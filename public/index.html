① SAP 발주 파일 올리기

SAP에서 내려받은 발주 목록 엑셀(.xlsx)을 고르거나 여기로 끌어다 놓으세요.

또는 발주 목록을 제목줄까지 전체 선택(Ctrl+A) → 복사(Ctrl+C) → 아래 칸에 붙여넣기(Ctrl+V) 하세요.

  • 삭제: Purchase Type Indirect·공란 / Row Status C·공란 / Price Currency KRW 아님·공란
  • 중복: PO number·Posting Date·Delivery Date·Item No.·Vendor Name이 모두 같으면 가장 최근(아래쪽) 줄만 남김
  • 입력해 둔 납기예정일과 기존 납기일은 그대로 유지
  • 단가 관련 열은 저장하지 않아요

② 거래명세서 입고 올리기

공급사 거래명세서 엑셀(.xlsx)·PDF(스캔본 포함)를 고르거나 끌어다 놓으세요. 여러 개를 한 번에 올려도 돼요.

또는 receipt_raw에 붙여넣던 것처럼 아래 칸에 붙여넣으세요. 제목줄·합계줄·빈 줄은 알아서 건너뛰고, "10/16 착"에서 날짜를 읽어요.
